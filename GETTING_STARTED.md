# Getting Started with EnterpriseSync AI

## 🎯 Welcome!

Welcome to **EnterpriseSync AI** - your complete enterprise management platform. This guide will help you understand the project and get started quickly.

---

## 📖 What is EnterpriseSync AI?

EnterpriseSync AI is an **AI-powered unified enterprise ecosystem platform** that enables organizations to:

✅ Manage **Projects** and track progress  
✅ Assign and monitor **Tasks**  
✅ Manage **Employees** and departments  
✅ Track and allocate **Assets**  
✅ Predict **Risks** using AI  
✅ View **Analytics** and generate reports  
✅ Control access with **Role-Based permissions**  

**Tagline:** *One Platform. One Team. Smarter Enterprise.*

---

## 🌟 Key Features

### 🎯 Core Modules

| Module | Description | Key Features |
|--------|-------------|--------------|
| **Projects** | Project lifecycle management | Create, assign, track progress, deadlines |
| **Tasks** | Task assignment and tracking | Priority levels, status updates, deadlines |
| **Employees** | Workforce management | Profiles, departments, workload tracking |
| **Departments** | Organizational structure | Department hierarchy, location tracking |
| **Assets** | Asset inventory | Allocation, maintenance, tracking |
| **AI Risk** | Risk prediction engine | Risk scores, delay prediction, recommendations |
| **Analytics** | Data visualization | Charts, reports, KPIs |
| **Notifications** | Real-time alerts | Deadlines, assignments, warnings |

### 🔐 Role-Based Access Control

| Role | Permissions |
|------|-------------|
| **Admin** | Full system access, user management, all features |
| **Manager** | Create projects, assign tasks, view team reports |
| **Employee** | View assigned tasks, update status, view profile |

### 🤖 AI Capabilities

- **Risk Score Calculation** - Based on completion %, deadlines, pending tasks
- **Delay Prediction** - AI predicts potential delays in days
- **Smart Recommendations** - Actionable suggestions to reduce risk
- **Trend Analysis** - Historical risk patterns

## 🔧 Essential Commands

### Backend
```bash
# Start backend
cd backend
source venv/bin/activate
uvicorn main:app --reload

# Access API docs
http://localhost:8000/docs
```

### Frontend
```bash
# Start frontend
cd frontend
npm run dev

# Access app
http://localhost:5173
```

### Database
```bash
# Connect to database
psql enterprisesync_ai

# List tables
\dt

# Exit
\q
```

## 🆘 Getting Help

### Documentation
- Check the relevant guide in `docs/` folder
- Search through API documentation
- Review code comments

### Common Issues
- **Database connection failed** → Check PostgreSQL is running
- **Module not found** → Reinstall dependencies
- **CORS errors** → Check API URL in frontend .env
- **Port already in use** → Kill process or use different port
